## Workflow

1. **Confirm authorization first.** Only proceed if the target is owned by you, in-scope on a bug bounty program, covered by a signed RoE, or a deliberate practice lab (OWASP Juice Shop, testphp.vulnweb.com, Hacker101 CTF). If unclear, state assumptions and ask before continuing — validation gates auto-trigger on ambiguity.

2. **Describe the target and vuln class in plain English.** No slash commands or skill names needed — e.g. "I'm testing the login flow on juice-shop.herokuapp.com for auth bypass" auto-loads the relevant `hunt-{class}` skill (e.g. hunt-xss, hunt-sqli, hunt-csrf) plus `bb-methodology`.

3. **Recon before hunting.** Enumerate endpoints, parameters, and entry points specific to the target (use `web2-recon`/`offensive-osint` patterns) before firing payloads — don't skip straight to exploitation.

4. **Run detection patterns from the 681+ disclosed-report corpus.** Each `hunt-{class}` skill contains per-class detection patterns, exact payloads that have worked in real HackerOne reports, and bypass tables — apply these against the enumerated surface rather than generic payload lists.

5. **Test payloads and bypasses.** Use curl/browser for basic cases; Burp Suite (or Burp MCP integration if wired in) for intercept/replay-heavy classes. Iterate through the bypass table if the first payload is filtered.

6. **Validate before reporting: run the 7-Question Gate.** Do not submit or write up a finding until it passes this gate — it exists specifically to kill false positives. Outcomes are one of: PASS, KILL, CHAIN-REQUIRED, or DOWNGRADE. Only PASS findings move to reporting.

7. **If new to the bundle/workflow, practice first** on OWASP Juice Shop, testphp.vulnweb.com, or Hacker101 CTF before pointing this at a live bounty program or client engagement.

## Notes
- Skills auto-load by topic — never invoke by name, just describe what you're testing.
- 48 of the skills are `hunt-` skills curated specifically from disclosed HackerOne reports, covering 24 core vulnerability classes.
- This phase (Hunt) sits between Recon (Phase 2) and Ship It (reporting/triage) in the 6-phase engagement workflow — don't shortcut past the Scope/Recon phases or the Validate gate.
- Requires Claude Code (Pro/Team/Max plan or Anthropic API key) with the bundle installed as a plugin or copied into `.claude/`.
